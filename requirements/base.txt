# swap-fase — cross-platform BASE dependencies (NO onnxruntime here).
#
# onnxruntime is INTENTIONALLY excluded from this file. The correct runtime
# package is platform/accelerator specific and is installed *on top* of these
# base deps by the platform installer (install.sh / install.ps1) or a Dockerfile:
#
#   Windows                -> onnxruntime-directml      (NVIDIA / AMD / Intel GPU; CPU fallback)
#   Linux + NVIDIA         -> onnxruntime-gpu[cuda,cudnn]==1.22.0  (CUDA 12.x + cuDNN 9.x)
#   Linux + AMD (ROCm)     -> onnxruntime-rocm           (may need a custom index) else CPU onnxruntime
#   Linux Intel / no GPU   -> onnxruntime                (CPU)
#   macOS (Apple Silicon)  -> onnxruntime-silicon        (CoreML) else onnxruntime (CPU)
#
# NEVER install both onnxruntime AND onnxruntime-gpu into the same venv — their
# files collide and the CUDA EP silently falls back to CPU. insightface may pull
# the CPU `onnxruntime` transitively; the installer reconciles that.
