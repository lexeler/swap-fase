<objective>
Acquire and integrity-verify the models into a project-local `models/` directory, then build the `FaceEngine` and prove the full swap path works on STATIC images with zero threading. `buffalo_l` auto-downloads; `inswapper_128(_fp16).onnx` is fetched from a community mirror and SHA256-verified (fail-closed). `FaceEngine.embed(photo)` caches the largest source face once; `FaceEngine.process(frame, target)` swaps the largest detected face. A throwaway `swap_still.py` swaps one still onto another and writes the result — validating the model path before any real-time complexity is added.

Purpose: Steps 3–4 of the ROADMAP risk-first build order. De-risks model acquisition/integrity (Pitfall 5) and validates the InsightFace API + provider wiring on the simplest possible input (one image, no threads) before the live pipeline depends on it.
Output: `bootstrap.py` (model download + hash verify), `engine.py` (FaceEngine), and a `swap_still.py` that produces a visibly swapped image on the GPU.
</objective>
