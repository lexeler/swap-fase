# Requirements: Swap-Fase

**Defined:** 2026-05-29
**Core Value:** Открыл приложение → подключилась вебка → моё лицо в реальном времени заменено на лицо с загруженного фото, и это идёт плавно.

## v1 Requirements

Требования для первого рабочего релиза. Всё укладывается в одну фазу (по запросу пользователя).

### Environment & GPU (ENV)

- [x] **ENV-01**: Все зависимости ставятся в изолированный project-local venv; глобальный/общий Python-venv не затрагивается
- [x] **ENV-02**: NVIDIA-драйвер работает (`nvidia-smi` отвечает) — устранён рассинхрон модуля ядра (`dkms autoinstall` + `modprobe nvidia`, ребут как fallback)
- [x] **ENV-03**: CUDA/cuDNN ставятся локально в venv через pip (`onnxruntime-gpu[cuda,cudnn]`), система не трогается
- [ ] **ENV-04**: Модели (`buffalo_l` + `inswapper_128.onnx`) скачиваются один раз в project-local `models/`, проверяются по SHA256; дальше работа офлайн
- [x] **ENV-05**: На старте приложение проверяет, что инференс реально выполняется на CUDA (а не тихо упал на CPU), и фиксирует фактический провайдер

### Face Swap (SWAP)

- [ ] **SWAP-01**: Пользователь загружает одно фото-цель; в нём детектится лицо (берётся крупнейшее), эмбеддинг источника вычисляется и кэшируется один раз
- [ ] **SWAP-02**: В каждом кадре с вебки детектится лицо пользователя и заменяется на лицо-цель (InsightFace `inswapper`)
- [ ] **SWAP-03**: Если лица в кадре нет — кадр проходит без изменений (passthrough), без падения приложения

### Real-Time Pipeline (LIVE)

- [ ] **LIVE-01**: Захват видео с веб-камеры (`/dev/video0`) с возможностью выбрать устройство
- [ ] **LIVE-02**: Конвейер capture → inference → display в раздельных потоках с очередью «keep-newest» (maxsize-1), чтобы задержка не накапливалась
- [ ] **LIVE-03**: На GPU своп идёт плавно (цель 25–30+ fps); при отсутствии рабочего GPU — деградированный CPU-fallback, приложение остаётся работоспособным
- [ ] **LIVE-04**: На экране отображается счётчик FPS

### Interface (UI)

- [ ] **UI-01**: Окно приложения (PySide6) показывает живой свопнутый видеопоток
- [ ] **UI-02**: Кнопки старт/стоп свопа
- [ ] **UI-03**: Смена фото-цели из интерфейса без перезапуска приложения
- [ ] **UI-04**: Тумблеры «своп вкл/выкл» и «зеркало (mirror)»
- [ ] **UI-05**: Индикатор активного провайдера (GPU/CPU)

## v2 Requirements

Отложено на следующие вехи. Зафиксировано, но не входит в текущий roadmap.

### Virtual Camera (VCAM) — следующая веха

- **VCAM-01**: Вывод свопнутого видео в виртуальную камеру (`v4l2loopback`, уже установлен) для созвонов
- **VCAM-02**: Выбор этой виртуальной камеры в Zoom / Meet / Discord

### Quality (QUAL)

- **QUAL-01**: Опциональное улучшение лица (GFPGAN/CodeFormer), по умолчанию ВЫКЛ (≈ вдвое режет fps)
- **QUAL-02**: Маска рта / сглаживание краёв для более чистого блендинга

## Out of Scope

Явно исключено, чтобы не было расползания скоупа.

| Feature | Reason |
|---------|--------|
| Обучение модели на наборе фото (DeepFaceLive / DFM) | Для личного «поиграться» избыточно; single-image `inswapper` проще, быстрее, соответствует «лицо на то, которое загрузил» |
| Публикация, стриминг, запись на диск | Только локально, ничего не публикуется |
| Мобильная или веб-версия | Только локальный desktop на этой Linux-машине |
| Мульти-таргет маппинг нескольких лиц | Не нужно для одного целевого лица |
| Системная установка CUDA toolkit | Прямое требование: только project-local через pip |
