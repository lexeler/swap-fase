# swap-fase — Linux + NVIDIA reference pin set (this machine's reproducible install).

# This file = cross-platform BASE deps + the Linux+NVIDIA onnxruntime, so the
# existing `uv pip install -r requirements.txt` on this reference host keeps
# working unchanged. Other platforms must NOT use this file directly — run the
# platform installer instead (install.sh on Linux/macOS, install.ps1 on Windows),
# which layers the correct onnxruntime on top of requirements/base.txt.
#
# Install with uv (preferred) into an isolated venv — NEVER the global/shared env:
#   uv venv --python 3.12 .venv
#   uv pip install --python .venv/bin/python -r requirements.txt
#
# CUDA 12.x runtime + cuDNN 9.x come from the onnxruntime-gpu [cuda,cudnn] extras
# below — NO system CUDA toolkit (CLAUDE.md "What NOT to Use").
#
# IMPORTANT: install ONLY onnxruntime-gpu in this venv. Never the CPU
# `onnxruntime` package alongside it — they collide and cause a silent CPU
# fallback. insightface pulls `onnxruntime` transitively; it must be uninstalled
# and onnxruntime-gpu (re)installed (see install.sh, which handles this).
